# Using it day to day

| You want to… | Do this |
|---|---|
| Capture something | Open the page, type it, pick an area (or let the planner pick) and how soon, then **Save**. |
| Add a deadline or importance | Open **Importance and due date** under the capture box. |
| Get something done today | Pick **Urgent: today**. It's placed within the hour during work hours. |
| Get it first thing tomorrow | Pick **Urgent: tomorrow AM**. |
| Park an idea | Pick **Someday**. Tap **Plan this** when you're ready. |
| Approve the plan | Do nothing. Blocks left on the calendar are approved. |
| Move a block | Drag it on your calendar. It stays where you put it from then on. |
| Drop a task | Delete its block on the calendar. |
| Finish a task | Tap **Done** on the page. Undo is under **Completed**. |
| Change a project | **Adjust** on the project: area, urgency, importance, or a note. It re-plans on the next run. |
| Take a day off or a lighter day | **Settings → Out of office and lighter days**. |
| Add a weekly task | **Settings → Recurring tasks**. |
| Protect a personal appointment | Put it on your personal calendar as **busy**. Mark reminders as **free** or start the title with "Reminder". |
| See why something wasn't scheduled | Check the status banner, and the "planned ~" dates on the project. |

## What the colors mean

| Color | Meaning |
|---|---|
| Tomato | Urgent |
| Your area colors | Task blocks by area |
| Graphite | Out of office and travel |
| Flamingo | Break + email |

Colors are applied by the color script, usually within an hour of the morning run.

## A good weekly habit

Once a week, skim **Someday** and **Projects**. Plan what's ready, park what isn't, and drop what no longer matters. Five minutes keeps the list honest.
